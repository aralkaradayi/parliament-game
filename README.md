# Turkish Parliament Quiz

A quiz game about Turkish parliamentarians of the late 1990s

## About

This project is an interactive quiz where players try to identify the
political party affiliation of Turkish parliamentarians based on their physical 
traits and preferences of fashion.

## Features

- Questions based on Turkish parliamentarians from the 1990s
- Multiple-choice answers
- Score tracking
- Names and party allegiances of the parliamentarians
